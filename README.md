## 🛠️ Things I've built (and occasionally broken)

### 🏛️ Pantheon — Multi-Agent Project Intelligence

![Multi-Agent Systems](https://img.shields.io/badge/Multi--Agent%20Systems-6554C0?style=flat-square)
![Process Intelligence](https://img.shields.io/badge/Process%20Intelligence-26856A?style=flat-square)
![Systems Integration](https://img.shields.io/badge/Systems%20Integration-176B87?style=flat-square)

**What it does:** A multi-agent solution supporting project governance and operational decision-making across a **BRL 20M+ project portfolio**.

One of its more interesting workflows connects **AS-IS process knowledge** to **TO-BE system requirements**: chunking operational information into "data endpoints", matching it against actual system capabilities through JWT requests to a proper and isolated code-analysis agent, and turning the findings into documentation people can use.

**The real challenge:** making agents clearly translate between logistic operational information and system features, not in critical aspects, but in the boring small details. A configuration toggle buried in an ever-changing system can be the difference between a beautiful recommendation and a very expensive misunderstanding.

*If you think AI consumes a lot of water, you should've seen how much coffee this one took for my team.*



### 🌌 The Eternal Simulation — An Incremental Universe, Because Why Not?

![JavaScript](https://img.shields.io/badge/JavaScript-323330?style=flat-square&logo=javascript&logoColor=F7DF1E)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Simulation](https://img.shields.io/badge/Simulation%20%26%20Math-AD5389?style=flat-square)

This one is here because I genuinely love it.

It's a browser-based incremental game where you condense cosmic radiation into usable energy, build increasingly absurd equipment, and gradually turn a tiny experiment into a very busy universe.

The game is primarily written in **JavaScript**, with some **Python** supporting the number-crunching experiments. At one point, **100+ interconnected entities** can influence one another's performance and calculations.

**The real challenge:** I thought astronomically large numbers would be the headache. Nope. It was designing mathematical models and an extensible class structure so I could keep expanding the game without rewriting the universe every Tuesday.
